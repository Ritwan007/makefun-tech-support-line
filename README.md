One funny line a hopeless tech support agent says to a desperate customer, for the [make.fun competition "Have You Tried Turning It Off?"](https://make.fun/competitions/u-motasimfuad-have-you-tried-turning-it-off-154a938b).

`main.py` writes the line to `/output/entry.txt`:

> Have you tried turning it off and on again? It worked for my marriage. Well — half of it did.

Run it with `python3 main.py`. The line was chosen from 34 fresh candidates by a round-robin gauntlet scored against the judge's brief (see the build notes in the workspace, not shipped here).
